# 桌面端 spec (跑批 16h 写的, 架构定死再动手)

## 定位
纯主控 GUI: 连 远端机 :11250 (视频/图/歌) + 本机 :7861 (出歌) + 远端机 大模型 :11250/llm.
本地零 GPU 权重 — 本机只做主控 + 出歌. 全部推理在 远端机.

## 框架
SwiftUI native macOS app (macOS 14+), 单 WindowGroup, 无 storyboard.
本机 3.9 不管 (那是 /usr/bin), Swift 用 Xcode CLT 的 swiftc.
产物: <仓库>/Desktop.app (bundle, 无签名, 本机自跑).

## 主界面
- 顶栏: 远端机 状态灯 (curl /health free_gib + loaded engines), 一键 unload
- 左侧 tab: 出视频 / 出图 / 出歌 / 大模型 / 队列日志
- 出视频: prompt 输入 + 秒数 (3/5/8) + steps (4/8/12) + 会话开/关
  - 出片自动播放 (AVKit), 显示 file:// 路径
- 出图: prompt + 尺寸预设 (1344x768 横 / 768x1344 竖 / 1024 方) + steps
  - 出图自动显示 PNG
- 出歌: prompt + 秒数, 走本机 7861, 出完自动播放 MP3/WAV
- 大模型: 问答, 显示回复
- 队列日志: 滚动显示每条调用 + 耗时 + 成功/失败

## 数据流
GUI -> URLSession GET 远端机:11250/xxx (query 参数) -> JSON {url,file:// 或 reply}
-> 本地 AVPlayer/AVAudioPlayer/NSImage 播放.
所有请求带 timeout, 409 (已在出片) 显示 "排队中, 等待".
11250 不可达 -> 顶栏红灯 + 全 tab 禁用.
