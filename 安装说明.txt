MLX Serve Studio 1.3 —— 桌面端安装说明
=====================================

【装 —— 只有 一 条 路】
  1) 下载 MLX-Serve-Studio-1.3.dmg
  2) 打开 DMG, 双击 "安装到本机.command"
  3) 等 它 跑 完 (会 打印 自检 结果)
  4) 装完 桌面 App 会 自己 打开; 终端 里 按 回车, 那个 窗口 会 自动 关掉

  装 的 时候 会 自动 先 清 一 遍 旧 文件 (/tmp 老 产物 · 探针 · 旧 缓存)。
  想 单独 再 清 一 遍 (或者 换 机器 时 清 干净): 双击 DMG 里 的 "清理旧文件.command"
  —— 它 不 动 模型 权重, 只 清 垃圾。

  就 这 么 简单。安装脚本 会 顺带 装 好:
    · 内核代码      ~/.ours/mlx_server/
    · 出歌引擎      ~/.ours/ace-step-engine/            (ACE-Step 1.5, MIT)
    · 出片引擎      ~/.ours/vendor/minimax-h3_mlx_src/   (MiniMax-H3 MLX, Apache-2.0)
    · 出图引擎      ~/.ours/vendor/krea2_engine_src/     (Krea-2-Turbo MLX)
    · 推理环境      ~/.venvs/mlxstudio/                 (mlx / numpy / mlx-audio)
    · 出歌环境      ~/.venvs/ace/                       (torch / diffusers, ~2GB)
    · 桌面 App      /Applications/MLX Serve Studio.app
    · 开机自启      ~/Library/LaunchAgents/com.ours.mlxstudio.plist  (端口 11251)
    · 产物目录      ~/Documents/MLX Studio 输出/
    · ffmpeg       ~/.ours/bin/ffmpeg                   (静态 arm64, 出片 压 mp4 用;
                    没 brew 的 机器 也 能 出 mp4 —— 以前 只能 出 帧 序列)

【唯一 需要 下载 的 —— 模型 权重】
  装完 打开 界面 -> 左侧「模型」页 -> 点「下载」
    出歌  ACE-Step 1.5 (~7.7G)   魔搭, 国内 直连
    出歌  MiniMax Music3 (~8.6G)  魔搭, 国内 直连
    出图  Krea-2-Turbo (~15G)     hf-mirror (自动 兜底 魔塔)
    出片  MiniMax-H3 (~130G 底模 + 本地 量化 出 4bit ~25G)   hf-mirror
    对话  Qwen3 0.6B / 4B / 8B, Gemma3-12B, Llama3-8B   hf-mirror
    语音  Qwen3-TTS / Kokoro-MLX / faster-whisper
  30 分钟 没 用 的 模型 会 自动 卸载 (不 占 内存); 连续 出歌 期间 不 卸载。

【要求】
  · Apple Silicon (M 系列) —— MLX 只 支持 苹果芯片
  · 网络: pip 走 清华源, 权重 走 魔搭 / hf-mirror
  · Python 3.10+ —— macOS 自带 的是 3.9 (不够, ACE-Step 用 新 语法);
    安装脚本 会 自己 找 (uv / Homebrew / 系统 都 试), 找 不 到 才 需要 你 装 一个
  · 磁盘: 装 完 约 6GB (引擎 + 依赖); 模型 权重 另外 下

【用】
  桌面 App 打开 就 是 主界面 (模型 / 监控 / API 接口 / 图像 / 视频 / 音乐 / 音频 / 资料库 / 代码启动器)
  视频 页 有 两个 标签: 「单个片段」和「批量首尾帧」。
    批量首尾帧: 选图池 (出图产物 一点 就 来, 也 能 加 本地 图片) -> 选 配对方式
    (两两配对 / 首尾相接 / 只做首帧) -> 写 提示词清单 (一行 一 条) -> 开始批量出片。
    整批 共用 一个 模型 会话, 模型 不 会 每 片 重 载; 产物 落在
    ~/Documents/MLX Studio 输出/视频/批次MMDDHHMM/
  API (OpenAI 兼容): http://127.0.0.1:11251/v1/chat/completions

【遇到 问题】
  · 第一次 打开 被 Gatekeeper 拦: 右键 App -> "打开" -> 再点 "打开"
  · 内核 没 起 来: 终端 跑
        launchctl kickstart -k gui/$(id -u)/com.ours.mlxstudio
        tail -50 ~/.ours/mlx_server/err.log
  · 没 内核/权重 时, App 会 停在 "内核 没 在 跑" 那 一 页, 不会 假 装 能用

【卸载】
  launchctl unload ~/Library/LaunchAgents/com.ours.mlxstudio.plist
  rm -rf /Applications/"MLX Serve Studio.app" ~/.ours/mlx_server ~/.ours/vendor \
         ~/.ours/ace-step-engine ~/.venvs/mlxstudio ~/.venvs/ace
  (模型 权重 在 ~/.ours/models, 想 留 就 别 删)

【说明】
  · 出歌 / 出片 / 出图 引擎 都 是 开源 的, 不 依赖 任何 闭源 App
  · 没 Apple 开发者证书 -> ad-hoc 签名, 别的 Mac 上 第一次 要 右键 "打开"
